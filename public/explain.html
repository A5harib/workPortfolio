4. Architecture Walkthrough & Pipelines

The portfolio operates on a decoupled serverless model using Next.js for the client/page rendering and Convex as the cloud backend engine.

// Data Fetching Pipeline:
1. Client components call hooks like useQuery(api.contacts.list) or useMutation(api.contacts.send).
2. Convex React Client communicates over a persistent WebSocket connection to the Convex Cloud Sandbox deployment.
3. Convex Cloud instantly executes queries/mutations and streams data updates back reactive to the Client.
